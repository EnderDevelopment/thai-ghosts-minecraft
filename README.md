# ThaiGhosts

ThaiGhosts is a Minecraft plugin that adds Thai ghosts into your world. It's designed to enhance the atmosphere of your server with eerie, ghostly entities that players can interact with. The plugin is built to be lightweight and efficient, ensuring it doesn't impact server performance.

## Install

1. Download the ThaiGhosts plugin JAR file from the [releases page](https://github.com/yourusername/ThaiGhosts/releases).
2. Place the JAR file into the `plugins` folder of your Minecraft server.
3. Start or restart your server to load the plugin.

## Use

1. Once the server is running, Thai ghosts will start spawning naturally in your world.
2. Players can interact with these ghosts using commands or in-game events as defined by the plugin.
